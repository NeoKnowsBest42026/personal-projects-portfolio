## Privacy

These projects began as personal working files. This portfolio contains descriptions only until public-safe copies have been reviewed. Do not add original files containing personal names, contact details, addresses, travel dates, immigration or identity documents, account information, private financial figures, or identifying video/audio. Use fictional or rounded sample data and remove hidden workbook sheets, comments, metadata, and document properties before sharing.

## Adding a project

Each project folder has a short README explaining its purpose, approach, and skills shown. Add only a reviewed public-safe sample when it helps a visitor understand the work. Keep personal originals in private storage.

## Git and GitHub, simply

- **Repository (repo):** a project folder stored on GitHub.
- **Git:** the change-history system that keeps track of edits to files.
- **GitHub:** the website that stores and displays the repository.
- **Commit:** a saved checkpoint with a short note, like “Add project descriptions.”

To publish this package without using Git commands: create a repository named `personal-projects-portfolio` on GitHub, download this folder as a ZIP (or select its files in File Explorer), then use GitHub’s **Add file → Upload files** page to upload the contents. Review the privacy checklist above before making the repository public. GitHub’s website saves the upload as a commit; you do not need to learn branches or command-line Git to start.
